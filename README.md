# DiY

Подбор радиодеталей. Обычная модель — `qwen2.5:3b`. Обученная — `diy-parts:q4`, это Qwen2.5-1.5B после LoRA и квантования Q4. Клиент переключает их кнопкой. Памяти на s1 на обе сразу не хватает, поэтому перед подъёмом одной вторая выгружается из Ollama.

Сервис на s1 слушает `8092`. Снаружи его отдаёт nginx на VPS, порт `8096`, прокси на `10.200.0.2:8092`.

## Где лежит модель

Адаптер и GGUF — на s1 в `/home/troot/diy/train/output`. В Ollama это отдельный тег `diy-parts:q4`. Тег `qwen2.5:3b` не перезаписывается.

## Перед выкладкой

1. Собрать датасет: `python3 train/build_dataset.py`. Контрольные фразы не входят в train.
2. Обучить LoRA в контейнере `lora-lab`, затем `train/merge_quantize.py`.
3. `ollama create diy-parts:q4` из `Modelfile`.
4. Короткий запрос к сервису на обеих моделях: мотор 12 В и паспорт BC547. Обученная должна назвать IRLZ44N и 1N4007.

## Откат

В интерфейсе нажать «Обычная 3B» или `POST /api/model` с телом `{"slot":"base"}`. Перезапуск контейнера тоже возвращает базовую модель: выбор хранится только в памяти процесса. Старый тег 3B остаётся на месте.
